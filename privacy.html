Privacy Policy for n8n Gmail Local

n8n Gmail Local is a personal-use application that connects a Gmail account to a self-hosted n8n instance through Google OAuth.

Google User Data Access

The application accesses Google Gmail data only after the user explicitly grants permission through Google's OAuth consent process.

Depending on the permissions granted by the user, the application may access email metadata and email content required for personal automation workflows.

How Data Is Used

Gmail data is used only for personal email automation, analysis, organization, workflow execution, and maintaining relevant context for those workflows.

Data Storage

Data processed by the application may be stored in the owner's self-hosted environment, including a self-hosted n8n instance and PostgreSQL database.

Data Sharing

Gmail data is not sold.

Gmail data is not shared with third parties except where required for the user-configured functionality of the application or where required by law.

Data Retention and Deletion

Data may be retained in the owner's self-hosted environment for as long as needed for the personal automation workflows.

Stored data can be deleted from the self-hosted environment by the application owner.

Revoking Access

Users can revoke the application's access to their Google Account at any time through their Google Account security settings.
