n8n Gmail Local

n8n Gmail Local is a personal automation application used to connect a Gmail account to a self-hosted n8n instance for email analysis, organization, and workflow automation.

The application accesses Gmail data only after the user explicitly grants permission through Google OAuth.

Gmail data is used only to support personal email automation workflows, including reading and analyzing email content, organizing messages, and maintaining workflow-related context in the user's self-hosted environment.

The application is intended for personal use only.
